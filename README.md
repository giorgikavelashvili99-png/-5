# MOON AI (Google Gemini, უფასო დონე)

ფაილები:
- `Index.html` — ჩატის გვერდი
- `server.js` — პატარა სერვერი, რომელიც გასაღებს იცავს და კითხვებს Gemini-ს უგზავნის
- `package.json` — გაშვებისთვის

## 1. გასაღების აღება (უფასოა, ბარათი არ სჭირდება)

1. გახსენი **aistudio.google.com** და შედი Google ანგარიშით.
2. დააჭირე **Get API key** → **Create API key**.
3. დააკოპირე გასაღები. არავის გაუგზავნო და GitHub-ზე არ ატვირთო.

## 2. ადგილობრივად გაშვება (კომპიუტერზე)

დააყენე Node.js 18 ან უფრო ახალი და ამ საქაღალდეში გაუშვი:

Windows (PowerShell):
```
$env:GEMINI_API_KEY="შენი_გასაღები"; node server.js
```
Mac / Linux:
```
GEMINI_API_KEY=შენი_გასაღები node server.js
```
შემდეგ ბრაუზერში გახსენი http://localhost:3000

## 3. ინტერნეტში გამოქვეყნება (Render)

1. ატვირთე ეს 3 ფაილი (`Index.html`, `server.js`, `package.json`) ახალ GitHub რეპოზიტორიაში.
2. Render-ზე: New → Web Service → აირჩიე ეს რეპოზიტორია.
   - Start Command: `npm start`
3. Environment Variables-ში დაამატე `GEMINI_API_KEY` = შენი გასაღები.
4. Deploy. Render მოგცემს მისამართს, რომელზეც ჩატი უკვე იმუშავებს.

## თუ Index.html სხვა საიტზე გინდა (მაგ. GitHub Pages)

- `Index.html`-ში `API_URL`-ს ჩაუწერე სერვერის მისამართი: `https://შენი-სერვისი.onrender.com/api/chat`
- Render-ზე დაამატე `ALLOWED_ORIGIN` = საიტის მისამართი (მაგ. `https://moonfull4k.xyz`), ბოლოში `/`-ის გარეშე.

## მოდელის შეცვლა

ნაგულისხმევია `gemini-3.6-flash`. სხვა მოდელის გამოსაყენებლად Render-ში დაამატე `GEMINI_MODEL` (მაგ. `gemini-3.8-flash`).
უფასო დონეს ლიმიტი აქვს (წუთში და დღეში, თითოეულ მოდელზე ცალკე). თუ მთავარი მოდელის ლიმიტი ამოიწურა, სერვერი თავისით გადადის სარეზერვო მოდელებზე
(`gemini-3.5-flash-lite`, შემდეგ `gemini-3.1-flash-lite`). მათი შეცვლა შეგიძლია Render-ში `GEMINI_FALLBACKS` ცვლადით (მოდელები მძიმით გამოყოფილი).
თუ ყველა ლიმიტი ამოიწურა, ჩატი ქართულად დაწერს წუთობრივი ლიმიტია თუ დღიური და რამდენი ხნით უნდა დაელოდო.

## ახალი ინფორმაცია და თარიღი

- სერვერი ყოველ კითხვაზე მოდელს დღევანდელ თარიღს აძლევს, ამიტომ ის აღარ დარჩება 2024 წელზე.
- ახალ ამბებზე, ფასებზე და ა.შ. ჩატი Google-ის ძებნას იყენებს და პასუხის ქვეშ წყაროებს აჩვენებს.
- თუ ძებნა რაიმე მიზეზით არ მუშაობს (ლიმიტი ან Google-ის მხარეს ცვლილება), ჩატი ავტომატურად ძებნის გარეშე პასუხობს და არ გაჩერდება.
- ძებნის გამოსართავად Render-ში დაამატე `GEMINI_SEARCH` = `0`.

## დაცვა

- გასაღები არასდროს ხვდება ბრაუზერში.
- ერთ IP-ზე ლიმიტია 20 შეტყობინება წუთში (`server.js`-ში `RATE_LIMIT`).
- შეტყობინების სიგრძე და ისტორია შეზღუდულია.
